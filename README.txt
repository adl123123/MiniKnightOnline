MINI KNIGHT ONLINE — запуск

1. Установи Node.js 18+.
2. Открой терминал в папке MiniKnightOnline.
3. Выполни: npm install
4. Выполни: npm start
5. Открой в браузере: http://localhost:3000

Для игры через интернет сервер нужно разместить на хостинге Node.js (например Render/Railway/Fly.io/VPS).
После публикации оба игрока открывают один и тот же адрес сайта.
Первый нажимает «Создать лобби» и получает 4-значный код.
Второй вводит код и нажимает «Войти».

Управление ПК:
WASD / стрелки — движение
ЛКМ — стрельба
Пробел — кувырок
1/2/3 — оружие
E — взять оружие / открыть магазин

На телефоне:
левый стик — движение
ОГОНЬ — стрельба
КУВ — кувырок
ВЗЯТЬ — взаимодействие
